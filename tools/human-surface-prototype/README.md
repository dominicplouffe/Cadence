# Human-surface reference prototype

`cadence.py` is a small, dependency-free Python script that implements
`add` / `list` / `done` / `schedule` exactly as specified in
[`../../docs/human-surface.md`](../../docs/human-surface.md) — same
wording, same column layout, same color/glyph rules, same error messages.

It is **not** the production CLI: it stores tasks in a flat JSON file
(`$CADENCE_HOME/tasks.json`, default `~/.cadence`), not the git-native
store the bake-off chose. Its only job is to make the design doc's claims
checkable against real terminal output instead of a written description of
one. `transcripts.txt` in this directory is the literal captured output of
running it — empty state, wide (120-col) and narrow (40-col) terminal
widths, color and `NO_COLOR=1`, a 200-character title, and all three
field-error cases — generated by re-running the script, not hand-written.

Try it yourself:
```
CADENCE_HOME=/tmp/cadence-demo python3 cadence.py add "Buy milk" --due 2026-09-01
CADENCE_HOME=/tmp/cadence-demo python3 cadence.py list
```

constraint forces a change, change `docs/human-surface.md` first.
